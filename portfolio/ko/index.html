// 개요

하나의 함대, 하나의 규율

하나의艦隊: 수십개의 작은 독립된 모듈 위에 구축된 대규모 제품 어플리케이션 — 공유 엔지니어링 헌장에 의해 관리되고 반부정 QA에 의해 검증됨. 주도적인 언어는 Go이며, Kotlin/KMP, TypeScript/React, Python, Swift, Shell은 각각 가장 적합한 곳에서 사용됨. 통일된 제안: 기능은 실제 사용자가 사용할 수 있을 때만 완료되며, 이를 증명하는 捕获된 증거가 있을 때에만 완료된다.
