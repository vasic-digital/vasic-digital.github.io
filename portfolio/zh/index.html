// 概述

一个舰队，一种纪律

一个舰队：在数十个小型、解耦、独立测试的模块之上构建的大型产品应用——由一个共享的工程宪法管理，并由反虚假 QA 验证。主要语言是 Go，Kotlin/KMP、TypeScript/React、Python、Swift 和 Shell 在适合的地方使用。统一的论点：一个功能只有在真正的用户可以使用它，并且有捕获的证据来证明它时才算完成。
